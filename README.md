# ATAK (코만도파크 내 위치 앱)

폰앱(`app`)과 갤럭시 워치앱(`wear`)이 들어 있는 안드로이드 스튜디오 프로젝트입니다.

## 1. 준비 (처음 한 번)

1. PC에 **Android Studio**를 설치합니다. https://developer.android.com/studio
2. Android Studio 실행 → **Open** → 이 `ATAK` 폴더 선택.
3. 아래쪽에 진행 막대가 돌면서 필요한 파일을 내려받습니다(처음엔 5~15분). 끝날 때까지 기다립니다.
   - "AGP Upgrade Assistant" 같은 업그레이드 창이 뜨면 **닫기/나중에**를 누르세요.
   - 빨간 오류가 나오면 아래 Build 창의 글자를 그대로 복사해서 Claude에게 보여주세요.

## 2. 폰에 설치

1. 폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 누르기** (개발자 옵션 켜짐)
2. 폰: 설정 → 개발자 옵션 → **USB 디버깅** 켜기
3. 폰을 USB로 PC에 연결하고, 폰에 뜨는 "USB 디버깅 허용"에서 **허용**.
4. Android Studio 위쪽 가운데에서 `app` 과 내 폰 이름을 고르고 **▶ (Run)** 버튼.
5. 폰에서 앱이 열리면 위치 권한을 **앱 사용 중에만 허용 + 정확한 위치**로 허용.

## 3. 워치(갤럭시 워치 4)에 설치

1. 워치: 설정 → 워치 정보 → 소프트웨어 정보 → **소프트웨어 버전 7번 누르기**
2. 워치: 설정 → 개발자 옵션 → **ADB 디버깅** 켜기 → **무선 디버깅** 켜기 (워치와 PC가 같은 와이파이여야 함)
3. 워치: 무선 디버깅 → **새 기기 등록(페어링)** → 화면에 IP 주소:포트와 6자리 코드가 나옵니다.
4. Android Studio: 기기 선택 목록 → **Pair Devices Using Wi-Fi** → **Pair using pairing code** → 워치를 골라 6자리 코드 입력.
5. 위쪽 가운데에서 `wear` 와 워치 이름을 고르고 **▶ (Run)**.
6. 설치가 끝나면 워치의 무선 디버깅은 꺼도 됩니다(배터리 절약).

폰앱과 워치앱은 **같은 PC에서 빌드한 것끼리만** 서로 연결됩니다.

## 4. 다른 사람에게 줄 APK 만들기 (폰앱만)

1. Android Studio 위쪽 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
2. 끝나면 오른쪽 아래 알림의 **locate** 를 누르면 폴더가 열립니다.
   `app/build/outputs/apk/debug/app-debug.apk` 가 폰앱입니다.
3. 이 파일을 카톡 등으로 보내면 됩니다. 받는 사람은 파일을 눌러 설치하고, "출처를 알 수 없는 앱" 설치를 허용하면 됩니다.

## 5. 쓰는 법

- 코만도파크 필드 중심에서 **1km 안**에 들어오면 지도가 켜집니다. 그 전에는 "필드까지 ○km"만 보입니다.
- **볼륨 위/아래**: 지도 확대/축소 (4단계). 화면의 **확대/전체** 버튼도 같은 기능.
- **잠금**: 버튼이 안 눌리게 잠급니다. 화면을 1초 길게 눌러 해제.
- **설정** 안에 있는 것:
  - **세로/가로 모드로 바꾸기**: 이 앱 안에서만 적용되고, 앱을 나가면 폰은 원래 회전 설정대로 돌아갑니다.
  - **좌표 표시**: 정보창의 현재 좌표(위도 N, 경도 E)를 켜고 끕니다.
  - **위치 보정**: 스폰처럼 확실한 지점에 서서 누른 뒤, 지도에서 그 자리를 터치. 한 번 하면 폰에 저장됩니다.
  - **보정 초기화**: 보정을 지웁니다.
  - **테스트 모드**: 집에서 확인용. 켠 순간의 내 자리를 필드 한가운데(C구역)로 가정하고, 실제로 걸은 만큼 지도에서 움직입니다. 앱을 다시 켜면 자동으로 꺼집니다.
- 워치는 폰앱이 **화면에 켜져 있는 동안**만 갱신됩니다. 워치앱을 끄려면 옆 버튼(홈)을 누르세요.

## 6. 값 바꾸고 싶을 때

`app/src/main/assets/index.html` 맨 아래 `<script>` 안:

| 바꿀 것 | 찾을 글자 |
|---|---|
| 지도 켜지는 거리(기본 1000m) | `NEAR_M=1000` |
| 확대 단계 | `ZL=[1,1.6,2.6,4]` |
| 스폰 위치(지도 픽셀) | `SPAWNS=` |
| 기준 좌표 | `ANCHOR=` |

워치에 보이는 범위(기본 250m)는 `wear/.../WatchActivity.java` 의 `VIEW_METERS`.
